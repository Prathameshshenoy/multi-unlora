THE MECHANISM

01 / ROUTE

Read the representation

The prompt’s hidden state is projected onto calibrated concept directions to set two correction weights.

02 / CONTRAST

Query the anti-experts

LoRA adapters trained toward undesirable behavior provide signals to subtract from base logits.

03 / DECODE

Moderate large shifts

A divergence guard attenuates large corrections. The resulting distribution selects the next token.
