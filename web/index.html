ABOUT

How it works

01 / ROUTE

Estimate weights

The prompt’s hidden state is projected onto calibrated concept directions to set two correction weights.

02 / CONTRAST

Compare adapter outputs

The model compares each adapter’s output with the base model, then subtracts the weighted differences.

03 / DECODE

Limit changes

A per-token KL budget limits changes to the distribution. The model falls back to its base distribution when necessary.
